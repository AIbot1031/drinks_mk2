## 實際訓練

RoBERTa 從固定官方 revision 5c58d0b8ec1d9014354d691c538661bf00bfdb44 開始，完成 1 epoch／75 optimizer 步，耗時 64.29 秒。2389 筆訓練文字、214 筆固定驗證文字；同品名跨品牌／杯型保留於相同分割。batch=32、max_length=64、learning_rate=1e-5、temperature=0.05、seed=42、MPS。

已核對目錄 SHA256、分割計數及上述參數全部與現有 MacBERT checkpoint 的原訓練相同；現有服務權重 SHA256 也與該歷史訓練報告一致。此次沒有再訓練 MacBERT，其歷史訓練 64.71 秒不是同時段效能對照。

dropout 對比驗證 loss：2.059937 → 0.006961；不拿它當排序改善證據。權重確實變更，保存後重新載入向量最大差為 0.0。本機權重：training_artifacts/20261015T005748-roberta-wwm-contrastive/model/model.safetensors；權重 SHA256：2d7aecfdae2f33744782b0a2d7cbeb868368d883391f877d97ebfa3d22200169。

## 判讀與限制

只依完整平均與逐查詢結果判讀，不只挑改善查詢。若平均提升但部分退步，需人工確認該類查詢。不同初始化模型的相同配方未必是各自最佳配方，這是一次控制條件實驗，並非完整超參數搜尋。

評估查詢未拿來訓練，但被推薦的目錄文字曾參與訓練，所以不是未見目錄測試。相近查詢彼此相關；二元標籤依目錄欄位，不代表清爽、回甘等人工口味相關性或用戶滿意度。缺漏茶種欄位的奶茶規則沿用前輪修正，其他目錄缺漏仍可能影響結果。

現有推論服務持續運作；本機計時不含網路、Worker、Qwen、RRF／RelGT，全目錄獨立檢索不是正式網站硬篩選後的完整流程。單輪延遲及峰值 RSS 受系統快取、其他程序及載入格式影響；RSS 與 MPS 統一記憶體不能相加。訓練峰值記憶體未量測，不估計。
