# MacBERT 與 RoBERTa 現行目錄比較

## 結果

依使用者先前要求，正式連線的語意服務已切回 MacBERT；版本為 `macbert-5754da458c249ff9`，MPS 裝置，索引與 3.1.23 目錄一致。這是模型選擇，不代表 MacBERT 在本次指標上勝出。

## 方法與限制

標籤由目錄中的茶種、奶類、配料與品牌欄位機械產生；按品牌及品名將尺寸與門市版本合成單一評估品項，再以最高版本分數排序，取前十名。查詢是人工撰寫的合成句，不是使用者偏好或專家評分；查詢涵蓋面有限且彼此相關。因此指標只表示這組目錄欄位測試的匹配情形，不代表真實滿意度或整體推薦品質。這也不是部署後點擊率或 A/B 實驗。

此次查詢是在完整目錄做編碼器檢索，未包含正式推薦的地區、門市供應、使用者偏好硬篩選、RelGT 融合、網路及 Worker 延遲。P95 與 RSS 是同一台 Mac 的單次進程量測，可能受快取和其他程序影響，不應外推成線上延遲或記憶體保證。
