## 判斷與限制

以本輪平均結果判斷，原始 RoBERTa 尚不足以支持替換現有微調 MacBERT；它在部分查詢較好，可以保留為 3.0 的比較候選。速度差異很小，單次共享 Mac 測量不能宣稱誰穩定更快。

這是 24 個合成查詢的目錄欄位代理評估，沒有人工口味相關性評分；未測主觀清爽／回甘、真實用戶滿意度與完整網站融合。初次結果發現部分奶茶 tea 欄位空白造成假陰性，已對有奶類且品名明示「奶茶」補足標籤規則，加入測試並完整重跑三個模型；保留先前 summary 並註記 superseded。其他資料缺漏仍可影響結果。未為了提高某模型分數調整查詢或去除弱項。

原始 MacBERT 與原始 RoBERTa 的比較較接近起始模型比較；原始 RoBERTa 與微調 MacBERT 的差值同時包含微調影響。MacBERT 曾使用目錄文字微調，因此本次不是未見目錄測試，也沒有新訓練前後比較。三者權重全程只讀，optimizer 步數皆 0。

下一輪可在相同資料、相同步數上微調 RoBERTa，並以事先固定的人工標註測試比較；查詢改寫互相關聯，需擴充獨立測試後再決定。使用者同意發布前不部署 3.0。
