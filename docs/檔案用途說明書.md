| 檔案 | 用途 | 使用方式與注意事項 |
| --- | --- | --- |
| `README.md` | 專案入口，交代開發範圍、安裝方式、原型狀態與資料限制。 | 新接手專案時先閱讀。本階段不實作路徑 C。 |
| `docs/檔案用途說明書.md` | 本說明書，維護每個檔案的用途。 | 新增、移除或更改檔案職責時同步更新。 |
| `data/飲料推薦系統_整理版.xlsx` | 使用者提供的飲料資料庫，保留原檔內容。 | 路徑 A 讀取「綜合飲料特徵」；其他工作表提供摘要、欄位說明與品牌統計。缺值保留未知，重複的過敏原表頭需另行核對。 |
| `references/route_a_original.py` | 使用者提供的路徑 A 原始參考程式，僅重新命名，內容未修改。 | 用於比對設計與追溯來源。原程式指定的 Excel 檔名與目前提供的檔名不同，直接執行需要另行準備原指定檔案。 |
| `references/architecture.png` | 使用者提供的融合式推薦架構圖。 | 用於理解需求理解、各推薦路徑、融合排序、解釋與回饋的關係。圖中的路徑 C 不屬於目前實作範圍。 |
| `src/route_a.py` | 可供接續開發的路徑 A 原型副本，調整專案根目錄與 Excel 路徑。 | 執行 `python src/route_a.py`。讀取 Excel、清理欄名、組合描述與 metadata、寫入 Chroma，最後執行範例查詢。原有推薦邏輯保持不變，尚未驗證完整執行結果。 |
| `requirements.txt` | 路徑 A 原型所需 Python 套件清單。 | 使用 `python -m pip install -r requirements.txt`。`pandas` 讀取與處理資料，`openpyxl` 支援讀取 XLSX，`chromadb` 儲存向量並查詢。目前未鎖定版本。 |
| `.gitignore` | 排除本機環境、快取、環境變數與向量資料庫。 | Git 自動使用；避免把 `.venv`、`.env` 或 `chroma_db` 提交到倉庫。 |

## 路徑 A 程式主要功能

1. `normalize_columns`：把中文欄位轉成程式使用的標準欄名，合併已知同義欄位。
2. `build_document`：將品牌、品項、風味、營養資料與特徵組成可搜尋描述。
3. `build_metadata`：保留顯示資料，建立熱量、咖啡因上下界與茶奶特徵等篩選欄位。
4. `load_drink_rows`：載入主表並略過沒有名稱的資料。
5. `main`：重建 Chroma 集合、加入飲料資料、執行語意與條件查詢。

目前尚未加入自然語言需求解析 API、路徑 B、融合排序或使用者回饋資料保存。路徑 A 中的篩選条件是查詢範例手動設定，尚不能自動理解所有使用者限制。

## 執行時產生的檔案

`chroma_db/` 儲存 Chroma 的本機向量資料；`.venv/` 儲存 Python 虛擬環境；`__pycache__/` 儲存 Python 快取。這些目錄不提交至 GitHub，可依安裝或建庫步驟重新產生。
