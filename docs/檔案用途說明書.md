## 路徑 A 程式主要功能

1. `normalize_columns`：把中文欄位轉成程式使用的標準欄名，合併已知同義欄位。
2. `build_document`：將品牌、品項、風味、營養資料與特徵組成可搜尋描述。
3. `build_metadata`：保留顯示資料，建立熱量、咖啡因上下界與茶奶特徵等篩選欄位。
4. `load_drink_rows`：載入主表並略過沒有名稱的資料。
5. `main`：重建 Chroma 集合、加入飲料資料、執行語意與條件查詢。

以上是 Python 參考原型的功能。網站 API 與路徑 A／B 基線另由 `worker/` 實作；Python 原型仍是手動查詢範例，尚不能自動理解所有使用者限制。

## 執行時產生的檔案

`chroma_db/` 儲存 Chroma 的本機向量資料；`.venv/` 儲存 Python 虛擬環境；`__pycache__/` 儲存 Python 快取。這些目錄不提交至 GitHub，可依安裝或建庫步驟重新產生。

`internal_exports/` 儲存匯出的推薦過程 JSON；`.dev.vars` 保存本機檢查密碼；`.review-access.txt` 保存團隊網址與密碼；`.wrangler/` 保存本機 Workers／D1 開發狀態。這些都是本機內部檔案，不提交 GitHub。node_modules 由 npm ci 安裝，不提交。
