# 3.0 心情推薦：科學依據與適用範圍

整理日期：2026-10-15（Asia/Taipei）。狀態：研究評估，未實作或部署。使用者授權成效良好時歸入 3.0 上線。這是針對需求的文獻查找，並非完整系統性回顧或本網站臨床驗證。

## 結論

有研究支持補水與部分疲倦感、含咖啡因紅茶與短期注意力，以及咖啡因可能干擾睡眠。這些可支持「依情境選擇」的設計；尚不能支持任何一款市售手搖飲保證舒壓、改善憂鬱或治療失眠。暫不以身心療效改動線上排序。

目前心情氛圍僅影響背景（docs/2.5更新說明.md）；worker/recommend.ts 已有排除估算咖啡因資料的上限篩選。不能將背景變色或既有推薦分數視為療效。

| --- | --- | --- |
| 喝水少、口渴且疲倦：白開水 | Pross 等（2014），52 名健康成人、短期調整飲水量；原本飲水少者增加飲水後部分疲倦與情緒評分改善。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC3984246/) | 非隨機、非盲法，Danone 資助；不能說喝越多越好，也不能延伸到含糖飲料。可寫「若今天喝水少，先補充水分」。證據有限。 |
| 白天希望清醒：紅茶 | De Bruin 等（2011），兩項雙盲隨機交叉試驗；紅茶較安慰飲料提升部分注意力測驗及自評清醒度。[摘要](https://pubmed.ncbi.nlm.nih.gov/21172396/) | 作者有 Unilever 研發背景；短期認知表現不等於情緒治療。可寫「含咖啡因，可能有助短暫提神」，不能以此推薦睡前飲用或提高攝取量。無糖是產品選擇，不是原試驗證明的額外療效。 |
| 壓力後想放鬆：紅茶作為候選 | Steptoe 等（2007），六週雙盲隨機試驗，紅茶組部分壓力後恢復指標優於對照。[摘要](https://pubmed.ncbi.nlm.nih.gov/17013636/) | 不能推論單杯立即舒壓、所有性別／族群或所有配方都有效；咖啡因與睡眠需求可能衝突。僅適合附限制的研究介紹，不作焦慮情境的自動首選。 |
| 接近睡覺：已核實不含咖啡因的飲品／水 | Drake 等（2013），隨機雙盲交叉試驗，400 mg 咖啡因在睡前 0、3、6 小時皆干擾睡眠。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC3805807/) | 研究是咖啡因膠囊；不能說每杯茶都同等影響，也不能說距睡前六小時以外就保證安全。選無咖啡因是避免干擾的推論，不是證明該飲品有助眠療效。 |
| 想喝花草飲：純洋甘菊茶 | Chang 與 Chen（2016），80 名睡眠不佳的台灣產後婦女，飲用兩週；部分睡眠與憂鬱症狀評分短期改善，四週追蹤組間差異未維持。[摘要](https://pubmed.ncbi.nlm.nih.gov/26483209/) | 特定族群、對照為一般照護，不能外推所有人；不是所有花茶、茉莉綠茶或加茶底的混合飲。保留為低確定性的研究資訊，暫不作助眠推薦。 |
| 難過時想喝甜飲 | Mantantzis 等（2019），31 項研究、1,259 人的統合分析未支持碳水化合物攝取會急性改善心情。[摘要](https://pubmed.ncbi.nlm.nih.gov/30951762/) | 不等於否定個人的口味享受，但不能用「糖讓人快樂」給高糖飲療效加分。此為統合研究，非單一飲料試驗。 |

## 3.0 可落地的建議設計

1. 將「想提神」「準備休息」「想喝喜歡的口味」作為使用者可選的當下需求；不從一句難過推論精神疾病。
2. 白天提神可提供有可靠咖啡因資料的紅茶候選；睡前則優先提供可核實無咖啡因的選項。缺資料要明示未知，不能把零估算值或「無茶」標記視為無咖啡因。
3. 飲水少時提供白開水建議，即使目錄沒有販售水，也不要強行替換成含糖手搖飲。
4. 保留使用者預算、奶類與配料排除條件；口味偏好與研究依據分開顯示。未查證茶胺酸、可可黃烷醇或草本劑量的品項，不套用成分補充劑的效果。
5. 每項說明提供研究連結、適用條件與短句限制。可使用：「這杯含咖啡因，可作白天提神的選項；接近睡覺時建議改選無咖啡因飲品。」不使用：「喝完能治療焦慮／改善憂鬱」。

## 上線判斷與後續驗證

文獻足以支持上述有限度的資訊與情境選擇，但不足以確認現有目錄的單杯配方或網站推薦已改善身心。正式上線前需完成品項與官方咖啡因資料對應、衝突情境測試（例如疲累但準備睡覺）、未知值及否定語句測試、來源連結與介面驗證。只有這些驗證通過，才發布 3.0 的情境選擇功能；不能將通過程式測試描述為臨床成效。

若評估網站品質，可比較推薦相關性、條件違反率與使用者自願回饋；收藏／點擊率只能代表互動，不能代表健康改善。研究未涵蓋的疾病、過敏或個人治療問題，不由飲料排序推斷。

最初研究整理階段沒有訓練或部署。後續使用者要求加入推論規則並訓練三模型，實作與實際結果見[3.0 規則與三模型訓練](3.0心情規則與三模型訓練.md)。原有未提交的前端與其他模型評估工作不屬於最初研究變更。
