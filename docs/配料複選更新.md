# 配料複選與背景辨識度更新

2026-10-14，Asia/Taipei。延續網站 2.5，不改動既有 v2.5.0 發布標籤。

## 使用方式

手動設定的配料改為勾選按鈕，可同時選珍珠、布丁、椰果等。飲料須包含所有選項；不選則不限，可按「清除配料」或「重設」。符合條件的飲料可以有其他配料，篩選不會自動放寬。配料以目錄資料標記為準。

背景依複選混合呈現：深色圓珍珠、金黃焦糖布丁、奶白椰果方塊，以及其他配料的色彩與造型。粒子半徑由 5–14 調為 13–25 CSS px，手機採 0.9 倍；加入輪廓、漸層及高光，取消 Canvas 整體 0.72 透明度，配料一般透明度提高至 0.82。經過標題、結果摘要及頁尾文字區域時採 0.16，維持可讀性。背景底部同時呈現所選固體配料。保留手動動畫開關、本機記憶、減少動態預設與隱藏分頁停播。

對話可說「珍珠和布丁奶茶」、「再加椰果」、「不要珍珠」、「配料改成仙草」、「配料不限」。追加保留原選項，替換與清除更新全部配料，排除只移除相應項目。解除排除表示可以接受，並不自動要求加入。珍珠與波霸沿用同類配料規則。

## API 與相容性

`filters.toppings` 接受支援配料的陣列，最多 20 個，去除重複與珍珠／波霸同類項目；全部選項採 AND 篩選。零項不限制，單項正規化為原有 `filters.topping`，多項回傳 `filters.toppings`。舊單項請求繼續支援。推薦候選、換批、卡片所有杯型及最終條件核對共用篩選。

Qwen 舊單項輸出不會覆蓋規則已解析的多項配料；只採訊息中有根據的配料，保留品牌、數值、排除與奶茶條件。已消耗的配料從對話口味文字移出，避免清除後被舊 query 重新加入。本次沒有訓練或替換模型權重。
