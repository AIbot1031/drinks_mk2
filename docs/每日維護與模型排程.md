# 每日維護與模型排程

- 時區：Asia/Taipei。每天 22:00（含）至隔日 08:00（不含）停止本機模型推論，08:00 起自動嘗試恢復。
- 控制：Qwen、MacBERT、RelGT 及 Qwen relay。以 launchctl disable／bootout 停止、enable／bootstrap 恢復，不刪除權重，不重裝服務或更換 checkpoint。
- 網站維持既有備援：A 路徑 TF-IDF、B 路徑特徵圖；Qwen 不可用時使用既有規則流程。維護期間語意理解與個人化效果可能降低，並非網站完全停止。
- 這是本機 macOS 使用者 LaunchAgent，不是 Cloudflare cron 或 Codex heartbeat。`scripts/install_model_maintenance.py` 安裝獨立執行副本到 `~/Library/Application Support/DrinksMk2Maintenance`；排程為 `~/Library/LaunchAgents/local.drinks-mk2.model-maintenance.plist`。
- RunAtLoad 加上每 60 秒核對一次台灣時間，正常登入且清醒時於邊界約一分鐘內切換；每次檢查後結束程序。休眠／關機／未登入時無法提供準時啟動保證，主機恢復後再次核對。模型載入與網路連線仍需時間，08:00 不代表立即 ready。
- 排程會維持時段內設定，手動啟停模型可能在下一次檢查時被覆蓋。若要自行控制，先停止此排程。
- 暫停排程：`launchctl disable gui/$(id -u)/local.drinks-mk2.model-maintenance`，再執行 `launchctl bootout gui/$(id -u)/local.drinks-mk2.model-maintenance`。只停止排程不會自動啟動已停止模型。
- 重新安裝／啟用排程：`python3 scripts/install_model_maintenance.py`。`python3 scripts/model_maintenance.py --check` 僅顯示當下預期模式，不更動服務。
- 使用者另明確選擇暫停 Codex 每日 RelGT／MacBERT／Qwen 訓練（automation id `relgt`），之後手動恢復；此操作與 08:00 推論恢復分開。這次沒有觸發訓練或建立訓練結果。
