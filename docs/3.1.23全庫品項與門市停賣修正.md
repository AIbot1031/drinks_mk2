# 3.1.23 全庫品項與門市停賣修正

## 問題與修正

使用者指出虎尾 CoCo 推出門市沒有的 3Q 奶茶，以及「資訊一覽／請勿下單」混入飲料目錄。

實際開啟[你訂雲林虎尾店 23257](https://order.nidin.shop/menu/23257)，公開頁面沒有 3Q 奶茶。原始 `onShelfMenu` API 卻仍有 `3Q奶茶`（2643820327）與 `3Q鮮奶茶`（2643820192），而且 `is_enable`、`is_visible` 皆為 true。官方前台程式另讀公開的 `disableItemsRelationNew`；兩項分別在奶茶與鮮奶分類的停賣清單內。先前只看菜單欄位，是錯誤推薦的原因。

本版讓匯入器、地區門市目錄共用同一套停賣篩選，排除停賣分類與主品項；有供應排程而無法確認適用時間的品項也保守排除，抓取失敗或格式未知不視為可供應。地區推薦再要求名稱出現在當地已核對菜單，所有原始與新增版本都適用；品牌存在、寬泛的區域文字或模型高分均不能繞過。

新增共用的非飲料規則，同時用於 Python 匯入與 Worker 候選篩選，阻擋「一覽、資訊、請勿下單」、娃娃盲盒、提袋、杯套、混合搭配商品等。優惠分類內的真正單杯飲料仍保留。

## 全庫檢查結果

- 檢查發布前全部 9,282 筆：原始 5,781、你訂 3,151、官方補充 350；原本 41 品牌不變，沒有新增品牌。
- 原始 5,781 筆未發現本次資訊／非飲料規則命中，逐筆保留不變。
- 推薦目錄排除 194 筆：8 筆資訊或請勿下單項（包含 7 個娃娃資訊項）、3 筆搭配商品、183 筆已沒有可確認可供應門市的版本。
- 共 11 筆明顯不應作單杯飲料推薦的資訊／商品列，已從推薦目錄移除。其他 183 筆並非都不是飲料，不能混稱為錯誤品名。
- 新目錄 9,088 筆、3,814 個品牌與品名組合。逐筆稽核清單見 `3.1.23全庫品項稽核.json`，移除後規則命中為 0。
- 既有 41 品牌中，你訂公開收錄的 2,069 家門市全部核對停賣資料及菜單版本，皆成功；其中 1 家版本已更新並重新取得菜單。這不是全台所有實體門市的即時庫存盤點。
- 原始公開研究快照保留作稽核，並不作為推薦候選。歷史互動與用戶帳號未刪除。

本輪找到麻古官方[中部](https://www.macutea.com.tw/upload_image/carte/menu_M.jpg)、[南部](https://www.macutea.com.tw/upload_image/carte/menu_S.jpg)菜單圖片，以及茶之魔手[中南部價目表](https://www.teamagichand.com.tw/price/)。麻古兩套圖片價格不同且含季節標記，本次官方分區門市頁未找到虎尾兩店，沒有擅選一套套用。茶之魔手有 PLUS 等例外；此次保留區域參考，尚未當作兩家分店完整供應清單。

15 家既有待確認店各自補記 `menuSearchAttempts`，重新讀取已有的 SipSpot 品牌菜單並記錄雜湊；通用參考不當作逐店庫存證明。可不可仍有會員登入限制，星巴克預先點餐為會員 App；未登入、未付費，未增加其他品牌。這 15 家仍待確認。

## 驗證與限制

新增測試覆蓋全目錄非飲料規則、真正優惠飲料保留、停賣與排程、未知格式保守排除、缺少供應證據不放行，以及不勾配料的「虎尾 CoCo 3Q 奶茶」也不出現在候選或模型排序結果。

舊測試有兩個不再有效的假設：門市品牌存在就有可帶預算的候選、沒有停賣資料也可視為有效菜單。修正測試資料及預期以符合新限制後，重跑結果另於完成發布時補記；沒有為測試放寬正式地區或供應規則。

仍然是公開快照，不承諾即時庫存；完整售價、營養、成分與過敏原未知的欄位不補造。現有 RoBERTa 與 RelGT 只重建目錄索引及核對既有權重，未訓練、未新增付費服務，也不宣稱推薦準確率改善。
