## 改善內容

- 將大量連續表格改為「結果與診斷、解析與篩選、A／B 路徑、融合與選取」四個區塊。先看到實際結果與篩選數量，再展開候選及計算資料。
- 顯示 Qwen、文字編碼器與 RelGT 目前連線／就緒及版本，附手動更新與台灣時間；明示目前連線與歷史單筆模型不同，不能據此宣稱品質提升。
- 修正過時的「B 尚非 RelGT」說明；每筆記錄顯示實際模型、備援原因、推論耗時與事件數。缺欄位呈現未記錄，不捏造數字。
- 區分等待釐清、硬條件阻擋、無結果與實際備援。guest／no_history 屬正常個人化條件，不列為模型故障。對話的等待釐清即使底層使用阻擋標記，也只顯示待釐清。
- 搜尋及左側標題優先使用原始對話，而非只有清理後的口味；仍能搜尋原有 query。採參數化 D1 查詢，不新增資料表或保存更多事件。
- 提供有／無結果篩選與最近 50 筆搜尋摘要，明示這不是全站流量；卡片顯示回傳理由與 A／B 名次。
- 配料任一符合及優先分層依當筆紀錄顯示；歷史沒有此設定時不套用新版結論。
- 手機單欄、可橫向捲動的榜單表格；登出或授權到期清除已載入紀錄與摘要，使用請求序號避免遲到回應覆蓋新選取或登出後回填。
