# 3.1.0：飲料語意檢索改用 RoBERTa-WWM

更新：2026-10-15T11:02:10+08:00（Asia/Taipei）。使用者已授權等待 3.0 發布後再發布 3.1。本輪先確認正式 health／頁尾為3.0.0、GitHub main包含00c0f8e，再沿用該版全部情境規則進行升級。

## 使用者會看到什麼

手動與對話推薦的語意路徑A使用飲料文字微調 RoBERTa-WWM，畫面、mode與trace顯示實際模型，不再標成MacBERT。現有3.0睡前已知0mg咖啡因、預算、品牌／配料／奶類等硬性篩選、跨輪解除與研究限制說明保留。Qwen及RelGT權重不變，Mac離線／推論失敗仍改用TF-IDF。

正式模型：`roberta-wwm-2d7aecfdae2f3374`。本輪只發布先前已完成的75步候選，沒有額外訓練或修改每日訓練排程。每日既有MacBERT任務仍會產生其自身候選，不會自動發布或覆蓋RoBERTa。

## 為什麼採用

相同目錄、切分、1 epoch／75步與超參數下，24個固定合成查詢：RoBERTa訓練前P@10=0.5875、NDCG@10=0.5905；訓練後0.6958／0.7221；現有MacBERT為0.5958／0.6182。逐查詢14勝、7平、3負，退步項為紅茶拿鐵、奶蓋茶、植物奶飲料。單輪本機查詢中位數8.45ms，MacBERT7.89ms，不把共享機器單輪時間當穩定速度優勢。原始／訓練後完整比較保留於model-validation/20261015T005914-v3.1-encoders。

這是目錄欄位代理評估，並非人工口味滿意度或未見目錄測試；不能從此宣稱身心療效。本次發布的是平均代理品質較佳的候選，個別查詢仍可能退步。

## 實作與驗證

- 使用已驗證的LocalRoBERTa載入／索引程式，核對官方來源、權重及目錄SHA256、重載結果。離線24個查詢前10名全部重現既有結果，索引5781×768。
- Worker依實際modelVersion設定roberta-wwm或macbert，保留MacBERT回復相容性；前端與監控顯示實際模型。既有LaunchAgent名稱與macbert操作槽保留相容，只代表服務槽，不代表目前模型身分。
- 型別、build、Wrangler dry-run、JS語法及diff檢查通過；隔離本機Worker96項Node／HTTP測試全通過無略過；模型環境16項Python測試通過。無NumPy的標準Python環境額外核對12項，其中3項NumPy測試依相依套件缺少而略過；完整模型測試在有NumPy環境均已執行。
- 實際本機RoBERTa服務手動／對話與3個退步查詢共5項通過；停止本機服務後同5項確認TF-IDF備援，已知0mg／預算限制不變。此為隔離Worker故障測試，沒有為測備援故意停止正式服務。
- 正式5項再次通過；Qwen對只有睡前和預算的要求會先追問口味，追加清爽回甘、不要奶後出卡，原咖啡因與預算限制保留。首次測試因錯誤假定每則對話立即出卡而失敗，修正測試以涵蓋既有追問流程；未修改Qwen行為來遷就測試。
- 實際恢復舊MacBERT，確認ready與6款已知0mg推薦，再切回RoBERTa並重新完成線上測試；模型回復路徑已演練。Worker程式回滾未實際演練，保留3.0部署ID供需要時使用。
- 正式health／頁尾3.1.0，index/app/chat/wellbeing-sources四個資產hash與本機一致；本機監控回報RoBERTa-WWM、正確模型版本與running=true。

正式Worker部署：`526a505f-9206-46f5-a2f6-8d211b169a75`。前版3.0部署：`d11bff4b-57df-4b68-93f2-b5c6ad5b9332`。模型透過現有私有WebSocket連線，沒有公開Mac服務埠或發送憑證到瀏覽器。

模型回復命令（僅在本次發布的Mac與本機state存在時）：

```sh
.venv-training/bin/python scripts/install_roberta_service.py rollback
.venv-training/bin/python scripts/install_roberta_service.py activate
```
