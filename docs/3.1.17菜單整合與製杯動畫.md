# 3.1.17 菜單整合、縣市推薦與製杯動畫

## 行為

- 原表 5,781 筆紀錄與 ID 保留，加入你訂快照的 26,384 筆菜單版本、24,580 個品牌／品名組合。整合後 32,165 筆版本、25,866 個品項、404 個品牌，其中 397 個有可推薦資料，7 個菜單待確認。
- 原表與新菜單有 1,317 個同品牌同名品項重疊，推薦與圖鑑依品牌／品名共用卡片。新菜單先按正式舊品名對齊，並用正規化名稱、品牌代碼與基本價去重；重複來源合併適用門市 ID，而非丟掉門市差異。原杯型、營養與價格版本保留，跨品牌同名不合併。未知適用範圍不假定相同。
- 已取得 393 個飲料／咖啡品牌公開資料，包含複合餐飲；平台其他 217 個分類品牌仍保留在研究索引，尚未擅自視為飲料品牌。4,304 筆門市、4,302 份菜單、2 份菜單讀取失敗；6 個品牌未取得門市。KitchenNow 未取得可確定的飲料品項，連同上述 6 品牌標為菜單待確認。
- 來源包含餐點、加料、商品與套餐，只匯入啟用且可見分類直接列出的啟用飲料。分類不明的 4,950 個品牌／名稱保留在稽核報告，不加入推薦。餐點與非單杯套餐排除；本次保守分類可能漏掉特殊命名飲料，需後續人工確認。
- 菜單基本價格不保證包含必要選項，故只以「元起」報價保留，完整售價為空值；未推算杯型、熱量、咖啡因、茶種、奶類或配料。卡片顯示待確認與公開來源。未知欄位不通過對應數值、配方與排除配料的硬篩選。
- 一般模式不看地區。地區模式只需縣市，鄉鎮可略過；有選鄉鎮就限制該鄉鎮。新菜單飲料必須在選定範圍確有菜單列售紀錄，原表還須符合來源記載的地區適用範圍；指定門市／商場版或無法判定適用範圍者不視為符合。不能因虎尾有CoCo就套用桃園門市的價格、配方與營養。新菜單來源連結改選實際匹配地區的門市；無可解析的本地來源則隱藏連結，不能顯示外地範例店。沒有資料不跨區，菜單列售不代表即時庫存或必然可購。
- 門市選擇、手動輸入、供應、回報與門市查核 UI 維持移除；保留後端資料及 API，等待使用者另行指定 UI。
- 手動、對話與收藏偏好刷新共用實際 API 等待動畫。茶湯、波紋與氣泡循環，選到的珍珠、布丁、椰果等以不同形狀落入杯中。配料只供視覺提示，不修改查詢；成功、失敗均在 finally 收起，多個請求重疊時待最後一個完成。尊重 prefers-reduced-motion，不顯示虛構推理步驟、百分比或刻意延長等待。

## 模型與限制

未訓練、未重建神經索引、未改權重。目錄雜湊已更新，模型橋接仍驗證索引與目錄版本；不相符時使用既有 TF-IDF／特徵圖及即時偏好備援，不把舊模型結果冒充新目錄推論。原互動 ID 與公開歷史版本維持相容。新品牌配方不足時個人化可用訊號較少，不宣稱推薦成效提升。

公開快照與匯入稽核：`data/research/nidin/`、`data/nidin-import-report.json`。可重建：`python3 scripts/import_nidin_recommendations.py`，再執行 `python3 scripts/build_nidin_directory.py`。重新匯入原 Excel 後也須再執行以上步驟，避免覆蓋擴充目錄。沒有額外收費服務不等於超出既有用量額度也免費。
