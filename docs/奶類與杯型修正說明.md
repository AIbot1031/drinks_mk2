# 2.1 奶類與杯型修正說明

2026-10-13（台灣時間）

## 發現與修正

1. 原頁面的 SVG 奶色漸層與奶類 select 都叫 `milk`，`querySelector('#milk')` 先找到 SVG，值為 undefined，JSON 請求漏掉奶類。選單改為唯一 `milk-filter`，label 與讀取一起更新；檢查整頁 ID 沒有重複。
2. 掃描全部 5,781 筆紀錄，原 3,411 筆無奶標記中有 85 筆與品名／奶類文字或旗標矛盾，改成不通過無奶篩選。保留原 Excel 不改寫；不是直接推定為鮮奶。完整可追查清單見 `奶類全表檢查.json`。
3. 無奶需來源標記為無奶、沒有已知奶類、沒有矛盾線索；可用紀錄為 3,326 筆。鮮奶表示含鮮奶標記，植物奶排除同時已標記鮮奶／奶精的版本。不是過敏安全或已查證完整配方。
4. 文字鮮奶／植物奶與手動選單衝突時停止推薦，而非悄悄忽略其中一個。

## 同品項單卡與最低價

- 品項用品牌＋完整品名分組；不同品牌、名稱仍分開。大中小杯、同名地區版本收在同一張卡。
- 底層 5,781 筆仍各自保存，不平均價格、熱量或咖啡因，也不合併營養數值。
- 每張卡預設顯示符合本次硬篩選、未被不喜歡／換批排除版本的最低價。不按地區選價，地區資料僅保留作來源。
- 杯型選單顯示版本及價格；切換後整張卡的營養、來源列、估算標記與收藏目標都切換到該 ID。
- 換批按品項排除，避免下一批又出現同品項另一個尺寸。
- 品項排序可由最匹配版本提供排名，卡片預設最低價版本。`rankSourceId` 保存真正參與排序的版本，consumerOutput／finalOrder 保存展示版本；不把便宜版本的來源列冒充匹配版本。
- 手動、對話、圖鑑與收藏卡採共同渲染。圖鑑以品項分頁，另外保留 variantTotal；收藏依已保存 ID 對應的品牌＋品名展開目錄中所有杯型／地區版本；既有只收藏大杯或小杯的紀錄也適用。收藏頁不套用推薦頁的價格或營養篩選，切換後須自行查看該杯型數值。

## 驗證範圍

新增回歸檢查遍歷全目錄的無奶／鮮奶／植物奶可用版本，核對每張推薦卡的版本均符合硬條件、品項唯一、最低價與換批不重複。同時保留原先過敏、營養未知、品牌排除與帳號測試。

實際網頁操作確認「無奶」送出後顯示無奶條件標籤，可用筆數由 5,781 降為 3,326，且推薦不再包含圖中的鮮奶飲料。大中小杯以選單呈現；沒有宣稱已逐一向 41 家品牌驗證真實配方。
