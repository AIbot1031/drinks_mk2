# 3.1.11 即時偏好推薦

## 需求與實作

收藏、不喜歡與取消任一操作保存成功後，手動推薦與最新一輪對話推薦自動更新。訪客保存於原瀏覽器；登入使用者以 D1 最新偏好為準，忽略瀏覽器傳入的舊偏好。保存失敗恢復最後確認的偏好，不執行刷新。

新增 `/api/preference-refresh`，重用原查詢的模型排名提示，重新驗證 query、filters、目錄與應用程式版本、分數及數量上限，不呼叫 Qwen、中文編碼器或 RelGT。排名提示存於瀏覽器記憶體，最多各 100 筆模型分數，不含帳號識別、歷史互動原文或權重；它是可由瀏覽器修改的排序提示，不是經驗證的新模型推論。伺服器始終重新執行篩選及品項排除，內部 trace 標明重用來源。過期版本要求重新查詢。

最新有效偏好按品牌＋品名去重，以茶種、奶類、配料及已標記的風味建立特徵支持度。每個特徵支持度為「支持品項數／（有效偏好品項數＋2）」，候選特徵取平均。只採用本輪未排除品牌的偏好。收藏與不喜歡兩側分開計算，分數有界，不按杯型或事件次數無限累加。

`最終分數 = 原 A/B RRF + 本機候選補充分數 + (0.22 × 收藏相似度 − 0.10 × 不喜歡相似度) / 61`

這些係數是可檢查的初始規則，尚未經用戶成效校準。模型 logit 不直接加到偏好分數。不喜歡的整個品項直接排除；同茶種或同奶類的其他品項只受到小幅扣分。取消操作會移除對應的即時加扣分及排除，不代表抹除既有模型已學到的歷史。

重用舊排名時，以目前合法候選的 TF-IDF／收藏特徵圖補足原模型 topK 未包含的品項，使取消不喜歡後的品項仍可進入候選。補充分數、來源與排序位置獨立記錄，不假冒模型 A/B 排名。空白查詢已有收藏時，維持以收藏圖為主，不用補充的文字排名蓋過它。

預算、營養、奶類、品牌、配料與品項排除仍經原篩選流程；既有「接近選擇」仍另列差異。刷新重設翻頁用的已看過清單，避免已取消排除的品項仍被批次清單擋住。對話條件與對話紀錄不增加一輪假訊息；研究說明以有限的情境類別保留，不在排名提示附上完整對話。

新增收藏頁「不喜歡的品項」及取消入口。保存與刷新期間暫鎖偏好及帳號切換操作，避免舊請求覆蓋新狀態。已保存的不喜歡會先從目前推薦卡片移除；刷新失敗明示失敗，允許重新查詢。歷史對話保留為過去紀錄，只有最新推薦輪次重算。

## 費用與模型

沿用現有 Worker、D1 與瀏覽器，不新增付費服務、資料表、排程或模型訓練。偏好刷新仍會使用既有 HTTP、D1 讀寫及 trace 配額，不能保證流量無限增加後仍在免費額度內。本次沒有訓練，沒有變更任何模型權重，也沒有模型品質進步的實證宣稱。

## 驗證

- TypeScript 檢查、前端 JavaScript 語法檢查、版本／建置一致性及部署 dry-run。
- 本機 Worker 全套 JavaScript／TypeScript 測試：131 項，125 通過、6 略過、0 失敗。略過項目需要未提供的模型連線金鑰或監督台測試環境。
- Python：意圖資料 5 項通過；其他 39 項測試通過（其中 7 項略過）。日訓練測試輸出為暫存目錄中的 fixture，沒有啟動實際模型訓練。
- 新增固定模型分數下的即時加扣分、取消、跨杯型去重、證據上限、未知 ID、營養硬篩選、名單外品項補充及排名提示驗證。
- HTTP 驗證訪客四操作、登入偏好優先、取消恢復資格、對話篩選保持、同源檢查、舊版本拒絕及睡前零咖啡因／研究說明保持。
- 本機瀏覽器驗證手動四操作、收藏頁取消不喜歡、對話自動更新並保持 50嵐／70 元條件。
