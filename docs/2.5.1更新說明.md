# 2.5.1：全站字體增加 2px

發布日期：2026-10-15，Asia/Taipei。

依使用者要求，全站原有 111 個明確 CSS 字級（主網站 97、團隊檢查頁 14）增加 2px；預設字級由 16px 改為 18px。響應式 clamp 保留原伸縮規則並加 2px，SVG 插圖與關係圖文字同步增加 2 個 SVG 單位。按鈕、表單、配料複選、推薦卡片、對話、目錄、關係圖與頁尾皆涵蓋。

桌面與 390×844 手機各量測 16 個主要元件，實際字級差值全部 +2px。桌面內容寬 1265／視窗 1280，手機內容寬 375／視窗 390，沒有頁面橫向溢出。實際查詢珍珠＋布丁紅茶、操作複選與查看卡片正常，瀏覽器沒有 console error。字級前後數值及正式資產 hash 見 [驗證紀錄](全站字體加大2px驗證.json)；[正式畫面](screenshots/2.5.1全站字體加大正式版.png)、[手機畫面](screenshots/全站字體加大2px手機版.png)。
