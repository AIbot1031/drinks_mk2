# 3.1.20：原品牌、既有模型、地區品牌與快速回報

使用者取消擴增品牌，推薦目錄回到原始資料的 41 個品牌。匯入器每次由原始非你訂列建立允許名單，阻止新增的 363 個其他品牌再次進入推薦。公開研究快照保留作來源存證，不代表已啟用推薦品牌。

目錄保留原始 5,781 筆與原 ID，加入原品牌的 3,151 筆菜單規格，共 8,932 筆、3,873 款品牌／品名產品。相同品牌品名仍合併一張卡，不同價格、杯型與門市適用證據保留；未知價格、成分與營養不補造。執行目錄共用與文字索引建置後，壓縮套件約 1 MiB。

RoBERTa 沿用已驗證權重，針對新目錄重建 8,932 × 768 索引。訓練報告只在目前目錄明列相容舊雜湊時允許重新建索引；權重雜湊仍嚴格核對，推論要求與快取仍核對目前目錄雜湊。原 5,781 筆向量與既有索引最大絕對差為 0。

RelGT 保留訓練產品的順序、編碼詞彙與全部權重，追加 1,270 個新產品至推論特徵表；新產品識別使用模型既有未知類別編碼，未核對的茶、奶、配料及數值使用缺值編碼，不能把未知配方當成無奶或無配料。原 128 個候選的同條件分數完全一致；新產品候選與新產品歷史可推論且可重複，全目錄實際推論通過。這次是重新索引與推論介面調整，optimizer 步數 0，未訓練、未更新權重，也不宣稱推薦準確率改善。原始訓練樣本只在本機記憶體驗證，不輸出至公開報告。

收藏、不喜歡、取消收藏與取消不喜歡仍套用每次請求最新快照；重用模型排名也會立即重新計分。同品名跨規格共用偏好，取消可恢復被排除產品。地區仍是硬限制；只選縣市即可。虎尾 CoCo 的其他地區版本不得借入，未確認配方不能通過芋圓或預算條件。

依地區推薦時，品牌選單及品牌排除清單只顯示該地區已收錄的原品牌。切換縣市／鄉鎮會清除無效品牌與舊卡片，再取得品牌清單；一般模式恢復 41 個品牌。清單代表目前來源收錄，並非宣稱當地所有門市已完整調查。

全站右下方新增快速回報，可選菜單、地區品牌、推薦或其他問題，填寫最多 1,000 字。附帶目前縣市／鄉鎮，不新增門市選擇介面。回報進入現有 D1 的獨立資料表，由既有團隊登入保護的待處理清單查看、標記已處理或關閉。消費者不能讀取回報清單。後端核對內容、來源、地區與可選品項；使用雜湊瀏覽器識別與每日筆數限制，同一回報識別碼可重送。單筆回報不會直接修改公開菜單或其他使用者的推薦。

## 驗證

- TypeScript、建置與 Wrangler 部署演練通過。
- 本機 HTTP 與 Node 測試 162 項：156 通過、6 項條件略過、0 失敗；包含地區品牌範圍、回報寫入、登入權限、團隊處理及收藏取消流程。
- 系統 Python 測試 47 項：39 通過、8 項因選用模型依賴略過；資料測試另 5 項通過。使用現有模型 Python 實測 RelGT／RoBERTa 契約 11 項全部通過。
- 真實模型證據：`model-validation/3.1.20目錄接回既有模型.json`。另保存快速回報成功、團隊可見及完成處理的本機畫面。
- 初次服務重啟遇到 launchctl bootout 後暫時無法 bootstrap；補入有限次重試後兩服務成功啟動，目錄雜湊相符。未更動 Qwen 服務、任何金鑰、LaunchAgent 參數或服務數量。
