# 3.1.18 目錄記憶體與地區修正發布

承接 [3.1.17 功能說明](3.1.17菜單整合與製杯動畫.md)：新舊菜單融合、同品牌同名共用卡片、保留適用門市差異、縣市即可選且地區硬限制、虎尾 CoCo 不跨用桃園版、配料製杯等待動畫。

3.1.17 曾以提交 `ab24a018c7850691f41224d182fdf11752a8228a` 部署為 Worker `5dd14629-fb02-4147-b9b6-6e689eceedba`，啟動231ms，但正式推薦冷請求出現503／1102。標記的後續自有驗證請求曾成功，仍不能排除資源用量臨界造成的不穩定；正式驗證不合格，已回復3.1.16 Worker `57c0a8dd-6175-4368-b35c-f68a156f382e`，健康檢查已核對。沒有建立3.1.17 Release，也沒有把不合格版本設為Latest。因已有部署，新修改另升3.1.18。

本次將重複的門市ID、地區陣列與文字欄位改成字典池，目錄展開後逐值核對全部32,165筆完全相同。TF-IDF 的每筆字串及 Set 改成共用詞典的整數向量，以二分搜尋查交集；範數仍依原 token 順序計算，維持浮點分數。目錄索引保留按需建置與快取，不存放使用者請求狀態，不改模型權重或推薦權重。

本機同一 Node／tsx 環境、強制GC後的常駐堆積量測（非Cloudflare正式端記憶體保證）：舊runtime目錄加舊索引約106.49MiB，新版約69.02MiB；其中索引增量從33.48降到19.72MiB。索引建置約177／190ms，這次主要降低記憶體，不宣稱建置加速。六個查詢（清爽、奶茶、果香酸甜、未知文字、空查詢、珍珠綠茶）比較舊／新引擎的完整推薦輸出相同。

驗證：本機Worker159項，153通過、6略過、0失敗；TypeScript與dry-run通過。先前Python44項（7略過）與意圖資料5項通過，本次沒有Python邏輯變更。未知價格／營養／配方仍不通過對應硬篩選，虎尾CoCo有效來源為菜單23257，3Q奶茶加芋圓未確認時空榜；供應不是即時庫存。未新增付費服務、資料庫、雲端資源、排程或更改方案，仍受既有額度限制。模型目錄版本不相符時採文字／特徵圖與即時偏好備援。

正式端冷請求、一般／地區／對話／偏好刷新、資產雜湊、瀏覽器與Release結果另補於daily.txt及線上驗證JSON。
