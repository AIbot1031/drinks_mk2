# 飲料推薦系統 2.0 更新說明

日期：2026-10-13（Asia/Taipei）

新版 Excel 的記錄單位、欄位與品牌名稱均與舊版不同。2.0 整套替換網站飲料目錄，不將兩版混合；GitHub 保留更新前的完整版本。

## 資料與來源

- 唯一目前來源：`data/飲料資料庫.xlsx`，原樣複製使用者提供的新版，沒有修改工作表內容。
- 工作表：「飲料品項」與「欄位規則」。網站匯入第一張表，5,781 筆杯型／地區紀錄、41 品牌，按品牌＋品名計 2,603 個名稱組合。
- 新版主數值已填滿，但不是全部官方精確值：600 筆價格、2,535 筆熱量、2,972 筆咖啡因為估算；3,232 筆無可確認的咖啡因上界。
- 保留杯型、容量、適用地區／門市、商品 ID、官網文字、填值方式與校準狀態。地區是來源描述，尚未實作定位／附近門市篩選。
- 特徵欄改為 0／1。茶種與配料選項從新目錄生成；新增抹茶、焙茶、麥茶、芋泥、奶蓋等選項。
- 過敏原 0 只表示官網未提及，仍不能用於判斷完全不含，維持過敏請求停止推薦。

## 新版匯入與推薦

- 匯入程式檢查新版工作表、必要欄位、有效品牌／品名、有限數值與非空目錄，避免沿用舊欄位後產生空資料。
- ID 依品牌、商品 ID、品名、杯型、地區與容量產生，不把價格與備註放入 ID，避免價格更新造成收藏改指別杯。5 個重複身份鍵保留為分別編號的來源列，不偷偷刪除原始紀錄。
- 畫面顯示杯型、地區與估算標記。價格上限排除估算價格；熱量上限排除估算熱量；咖啡因上限只使用明確上界，排除估算或無上界。
- 同品牌／品名的不同杯型與地區不再被當成完全相同紀錄去重。
- 修正無文字查詢但有收藏時，無關 A 排序蓋過 B 榜單：這種查詢使用收藏的 B 榜單；有文字查詢仍維持原 A/B 權重。
- 品牌排除、硬條件與推薦 trace 維持；更新 trace 範例以對應新版。

## 舊版保存及收藏限制

- GitHub `v1.0.0` 指向替換前的完整專案，包含舊版 Excel。這是保存標籤；更新前程式設定版本為 0.1.0。
- GitHub `v2.0.0` 為新版發布，package 與線上 health 版本為 2.0.0；main 使用新版。
- 主分支移除舊版 Excel，不另存混合來源。Git 歷史與 v1.0.0 保留，不重寫或刪除舊提交。
- 新舊粒度完全不同，未強行將舊飲料 ID 配成某一個新杯型。舊收藏可能需重新選取；帳號與歷史推薦紀錄沒有整庫清空。偏好 API 回傳時排除失效 ID，避免舊不喜歡 ID 造成後續保存失敗。
- 原始 Python 參考程式留作參考，專案原型更新來源與欄位，營養估算不作可確認上限；未完整重建／測試 Chroma 資料庫。
- 原 RelGT 價格測試權重對應舊資料快照，未在本次重新訓練或發布，不能當成新版模型。
