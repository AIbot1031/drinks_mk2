# 3.0 心情規則與三模型訓練

日期：2026-10-15（Asia/Taipei）。本版將[科學依據](3.0心情推薦科學依據.md)轉為有限度的情境規則，並實際執行三個模型各一次訓練。規則驗證與模型品質分開判斷；沒有宣稱網站已改善身心。

## 推薦規則

- 明確提到睡前、準備睡覺或避免失眠時，採咖啡因上界 0 mg；只接受目錄中非估算且已知的值，未知／估算不通過。這是避免咖啡因干擾的產品選擇，不是論文證明的助眠處方。
- 睡眠目標優先於同句提神或更寬鬆的咖啡因數值；Qwen 回傳的數值不能覆寫這項保護。品牌、預算、配料等仍需同時滿足，無結果不放寬。
- 跨輪與換批保留條件，使用者明確說「咖啡因不限」可解除；重新開始會清除。已消耗的睡眠字句不留在口味 query 反覆恢復條件。
- 只說晚上、疲累、難過不會自動加咖啡因／糖或指定茶種。提神、喝水少、低落可顯示對應研究說明，仍按使用者原口味排序。沒有以研究捏造排序加分或臨床分數。
- 有限詞彙規則排除部分否定、引號內文、第三人稱及假設句；不是通用語言理解或醫療診斷。未涵蓋的隱喻、反諷或複雜同句指涉仍可能漏判。
- 手動與對話介面提供可展開的論文連結與限制。對話確認文字不接受治療／助眠等療效說法；心情／健康情境的追問使用固定文字。

程式：worker/wellbeing.ts、understand.ts、conversation.ts、llm-conversation.ts、recommend.ts、index.ts；來源顯示：public/wellbeing-sources.js。

## 驗證與發布

隔離本機 Worker 8896、獨立 D1 執行 92 項 Node／HTTP 測試，92 通過、0 失敗／略過。HTTP 測試會接替同一模型角色，因此整套採單檔序列執行，避免並行測試互相撤銷 socket。8 項既有 Qwen／每日編排 Python 測試通過；編排測試使用替身，不是額外模型訓練。型別檢查、build 與 Wrangler dry-run 通過。

修正過的失敗：否定「沒有準備睡覺」誤判、口味正規化造成研究來源遺失，以及並行 HTTP 測試角色競爭。瀏覽器確認睡前 0 mg 條件、推薦卡片與可展開研究來源；本機無 Mac 連線時使用既有備援。

正式發布與 GitHub 同步結果將記於 daily.txt 與部署驗證檔；本文件不以本機驗證宣稱部署已成功。部署版本定為 3.0.0，套件、lockfile、頁尾與 API 共用版本保持一致。
