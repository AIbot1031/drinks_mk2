# 3.1.4：使用者輸入 → 實際回覆 → 推薦飲料

團隊監督台單筆詳情頂端加入對話式對照卡。顯示使用者原話、當輪實際回覆及所有回傳飲料的順序、品名、品牌、價格；登入／重新讀取後會自動選取最新一筆。原有解析、模型路徑及計算表格保留在下方。

## 記錄正確性

先前紀錄只保存聊天輸入與飲料結果，沒有保存實際 assistantMessage。此版本將既有回覆計算移到寫入紀錄之前，新紀錄保存與 API 回傳完全相同的 assistantMessage、choices、needsClarification；沒有重跑模型以重建文案。

手動模式新增 request.query／filters，於條件解析前複製已驗證輸入，只保存使用者這輪送出的文字與條件，不複製帳號、歷史對話或憑證。列表與搜尋支援該原始 query。沒有新增資料表或更改登入權限。

舊對話會標示「沒有保存當時的回覆文字」，只顯示實際保存的飲料；舊手動紀錄沒有原始 query 時標示「解析後文字・舊紀錄未保存原文」。手動模式沒有聊天回覆，直接顯示其飲料與當輪條件。不能把推估摘要冒充當時對話。
