# 3.1.2：配料任一符合與符合數量排序

選「珍珠、布丁、仙草」時，含任一種即可入選；符合三種先於兩種、再先於一種。同一符合數量沿用 A／B 融合及品牌多樣性。珍珠／波霸視為同種，不重複加分；未選則不限。預算、營養、品牌與不加配料仍為硬篩選。

手動及對話共用規則；條件標籤顯示「配料任一」，卡片列出實際符合數量。候選進入 A／B 前 100 名截斷前先按符合數量排序；模型服務本身只回前 100 名，因此額外保留服務未回傳但仍符合配料的候選，以中性融合分數參與配料優先分層，不捏造神經模型分數。

3.1.1 首次部署已通過 OR 及換批測試，但正式三配料測試發現上游模型截斷仍會漏掉符合更多種的品項，因此立即以新版本 3.1.2 補上候選保護。首次版本及驗證紀錄保留，不沿用同版本發布修正。

驗證：TypeScript 檢查、全套 97 項中 82 通過／15 需 HTTP 環境而略過；獨立 HTTP 配料套件再於本機及正式站測試。新增 110 個單料、4 個同品牌雙料的案例，確認低模型分數、品牌多樣性及模型只回前 100 名均不能壓掉更多符合配料的飲料。首次本機 HTTP 因隔離測試庫未套 migration 回 503，套用本機 migration 後通過，未動正式資料庫結構。

本次為推薦規則更新，沒有訓練或替換模型。版本、正式 API 與部署結果見線上驗證 JSON；資料欄位標記決定配料符合，不保證店家可自行加料或成分安全。
