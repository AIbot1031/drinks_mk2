# 3.1.24 品項目錄整併與門市明細

## 規劃

延續同品項合併工作：維護資料改為品牌／品名主項目加上多個杯型、價格及菜單來源版本；推薦介面仍以一張卡片呈現，並在地區模式中展開查看該版本對應的已核對門市。保留原品牌、品名、版本、來源欄位及 ID，不合併不同品名，也不推測門市供應。

## 實作

- 新增 `data/catalog-products.json` 作為主維護目錄，將 9,088 個飲料版本整理成 3,814 個品牌／品名主項目，版本保留獨立 ID、杯型、價格、營養、地區及來源；每個版本記錄原欄位次序，確保可重建舊目錄。
- `data/catalog.json` 改為建置產物並從 Git 移除。安裝套件、檢查、測試、建置及本機開發時會從主目錄產生，以相容既有推薦、模型索引及資料匯入流程。兩種匯入流程都更新主目錄與產物。
- 選擇地區時，推薦版本可展開查看該版本在所選縣市／鄉鎮核對到的門市名稱與地址；杯型選單也顯示該版本的門市數。門市資料由既有公開目錄及該版本的門市來源 ID 交集產生。
- 3.1.24；目錄重建後的 SHA-256 仍為 `d789342b95dbfe4feb5bdd5996298a97698a24216af441dc121b3d765fb545a5`，與前版相同；不需要重建模型索引或更動權重。

## 驗證

版本目錄由原始版本往返重建，所有 9,088 筆欄位及順序一致；型別、網站測試、Python 測試及部署 dry-run 結果待發布流程補記。

## 限制

只有依地區查詢時會列出對應門市；公開菜單是來源快照，不代表即時庫存。不同價格或杯型仍是各自版本，門市不明或 ID 無法對應時不會猜測或補列。此工作未執行模型訓練、未修改權重、未新增付費服務。
