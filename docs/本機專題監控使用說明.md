# 本機專題監控

在提供 Qwen／MacBERT 推論的 Mac 打開 [本機監控頁](http://127.0.0.1:8792)。Windows 或其他電腦的 localhost 不會連到這台 Mac。啟用區網模式後，同一 Wi-Fi 的裝置可用安裝程式印出的 Mac IPv4 網址查看；不公開到 Cloudflare。

每 3 秒顯示 Qwen、MacBERT、RelGT、安全轉接與監控程式的執行狀態、PID、作業系統 CPU 回報、RSS 記憶體與執行時間。GPU 顯示 MLX／PyTorch 在模型載入或完成推論時回報的配置記憶體及時間；不是 GPU 使用率百分比，不是持續取樣的 GPU 量測。RSS 可能包含共享頁面，與 GPU 統一記憶體也可能重疊，不能相加後當作精確獨占用量。

RelGT 推論已納入監控，訓練程序仍未接入。動作紀錄包含模型載入、預熱、網站連線、對話推論開始／完成／失敗、MacBERT 候選排序數量與耗時，以及加密轉接的建立／結束。只接受明確白名單欄位，不顯示原始文字、偏好內容、用戶 ID、密碼、金鑰、其他應用程式內容。監控只在 Mac 讀取這幾個指定服務的狀態與安全日誌，區網模式會將安全摘要提供給同一子網的瀏覽器，不把監控資料上傳雲端。

## 安裝與位置

- 執行 `python3 scripts/install_project_monitor.py`，會將程式複製到 `~/Library/Application Support/DrinksMk2Monitor` 並安裝 `~/Library/LaunchAgents/local.drinks-mk2.monitor.plist`。
- 登入後常駐、只在 `127.0.0.1:8792` 監聽。網址入口及 JSON `/api/status` 都檢查 Host／Origin，沒有任意檔案、執行指令或服務控制 API。
- 更新網頁或程式後重新執行安裝；使用既有 Python 基礎執行環境，不另安裝監控套件。
- 用 `launchctl bootout gui/$(id -u)/local.drinks-mk2.monitor` 暫停；再次安裝即可恢復。
- 登出、關機或移除既有 Python 執行環境時，程式不能運作。

## 已驗證與限制

已在實際 Qwen／MacBERT 推論後讀到兩者完成動作與 GPU 配置記憶體，監控 JSON 不含原始測試對話。異常 Host、外站 Origin 為 403，任意檔案網址為 404。單元測試確認動作日誌自動捨棄 prompt／key／userId 等欄位，網頁不能藉 Host 或路徑請求讀取檔案。

這是程序資源與模型動作監控，不是完整的作業系統檔案讀取鑑識工具；不能宣稱記錄所有系統呼叫或證明永遠沒有外洩。Cloudflare 雲端資源、其他應用程式及尚未接入的 RelGT 訓練程序不在本次量測內。顯示最近 40 個動作，標準輸出日誌仍由 LaunchAgent 保存，尚未新增自動日誌輪替。

## 同一 Wi-Fi 查看

- 安裝區網模式：`python3 scripts/install_project_monitor.py --lan`，以印出的 `http://<Mac 區網 IPv4>:8792` 從手機或電腦開啟。
- 僅綁定本機與預設網路介面的私人 IPv4，並檢查實際連線來源位於相同子網、Host 正確、Origin（若提供）與網址一致。沒有可用私人地址或子網遮罩時僅保留本機入口。
- 此模式沒有帳號登入，同一子網的裝置都可以查看安全監控摘要。請在自己的 Wi-Fi 使用。
- Mac 必須開機、保持喚醒並執行監控；手機須連相同 Wi-Fi。若網路啟用訪客隔離或 macOS 防火牆阻擋 Python 入站，其他裝置可能無法連線。
- IP 或 Wi-Fi 改變後重新執行安裝指令，以更新綁定與網址。停用區網：重新執行 `python3 scripts/install_project_monitor.py`。
- 不需要路由器連接埠轉送、Cloudflare Tunnel 或公開網域。
